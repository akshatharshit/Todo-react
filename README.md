## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/akshatharshit/Todo-react.git

# Navigate to project directory
cd Todo-react

# Install dependencies
npm install
```

## 💻 Usage

**🔧 Development server**
```bash
npm run dev
```
> `vite`

**📦 Build for production**
```bash
npm run build
```
> `vite build`

**🔍 Run linter**
```bash
npm run lint
```
> `eslint .`

**👀 Preview production build**
```bash
npm run preview
```
> `vite preview`

**predeploy**
```bash
npm run predeploy
```
> `npm run build`

**🚀 Deploy**
```bash
npm run deploy
```
> `gh-pages -d dist`
